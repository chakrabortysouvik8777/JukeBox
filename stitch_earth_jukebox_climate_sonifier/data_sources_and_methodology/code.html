Section 02 // Mathematical Architecture

Psychoacoustic Sonification Pipeline

From HDF5/NetCDF satellite matrices to polyphonic Web Audio scheduling in 4 deterministic mathematical stages.

STAGE 01 tune

Ingest & Normalization

Z-score normalization and bounded quantile scaling eliminate outlier noise while maintaining natural variance.

z = (x - μ) / σ
x_norm = (z - z_min)/(z_max - z_min)
  • 1951-1980 baseline reference
  • Bilinear interpolation to 0.25°
  • Clamped range: [-3.5σ, +3.5σ]
STAGE 02 graphic_eq

Logarithmic Pitch Scale

Maps continuous scalar anomaly units to human perceptual frequency space using equal-temperament microtones.

f = f_0 × 2^(cents / 1200)
cents = x_norm × 3600 (3 Octaves)
  • Fundamental f_0: 110.0 Hz (A2)
  • Microtonal quantization step: 12.5c
  • Dynamic limit: 880.0 Hz (A5)
